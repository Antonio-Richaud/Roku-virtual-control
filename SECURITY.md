# Security policy

This repository documents a recovery/interoperability workflow that handles Wi-Fi credentials generated by a Roku device. Those credentials must be treated as secrets.

## Never commit

- Roku WPS credentials
- Roku private WPA PSK / PMK
- `/etc/roku-remote-wpa.conf`
- `/run/*cred*`
- home Wi-Fi passwords
- SSH private keys
- raw packet captures containing credential exchanges
- logs that include unredacted `WPS-CRED-RECEIVED` payloads

## Recommended handling

- Store the persisted Roku WPA profile as root-owned mode `0600`.
- Use runtime files under `/run` for transient credentials.
- Redact WPS credential payloads before sharing logs.
- Read human-entered passwords with silent input when possible.
- Prefer Ethernet or a separate management interface so recovery scripts do not need to expose management credentials.

## Scope

Use the project only with devices you own or are explicitly authorized to service. Do not use it to access third-party devices or networks without permission.
